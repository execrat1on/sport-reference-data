# Sport Reference — открытые данные

Датасет доказательного справочника о спортивных добавках и тренировках:
**549 публикаций PubMed**, **103 разобранных добавок** с уровнями
доказательности A/B/C и дозировками под цели, недельные тренировочные объёмы по группам мышц,
25 упражнений и 37 продуктов.

Сайт: <https://sportreference.online/> · Страница данных: <https://sportreference.online/data/>

## Зачем это

Каждое утверждение на сайте сопровождается ссылкой на публикацию. Метаданные источников
не набирались вручную: заголовок, авторы, журнал, год и DOI подтягиваются из PubMed
E-utilities, а отдельный скрипт повторно сверяет базу с PubMed и падает, если запись
не найдена или не совпадает. Здесь лежит результат этой работы в машиночитаемом виде.

## Что внутри

| Файл | Содержание |
|---|---|
| `data/references.json` | Публикации: заголовок, авторы, журнал, год, DOI, PMID, тип источника и уровень доказательности |
| `data/supplements.json` | Добавки: механизм, дозировка под каждую цель, подтверждённые эффекты, ограничения, взаимодействия, формы, особые группы, источники |
| `data/training.json` | Недельный объём по группам мышц для пяти целей: частота, нагрузка, повторения, запас до отказа, кардио, периодизация, принципы |
| `data/exercises.json` | Упражнения по группам мышц с подсказками по технике |
| `data/foods.json` | Продукты, разобранные по макронутриентам |

**Чего здесь нет намеренно:** раздела о спортивной фармакологии, ПКТ и ГЗТ. На сайте он
справочный и закрыт подтверждением возраста; отдельным файлом эти данные не публикуются.

## Чего эти данные не означают

Это не медицинская рекомендация и не руководство к применению. Уровень A/B/C описывает
силу доказательств для конкретного утверждения, а не пользу для отдельного человека.
Дозировки приведены для взрослых и не заменяют консультацию врача. Там, где исследований
под цель не нашлось, вместо цифры стоит честная пометка — см. <https://sportreference.online/evidence/gaps/>.

## Обновление

Файлы выгружаются из основного проекта командой `node scripts/export-dataset.mjs`.
Метаданные публикаций обновляются скриптом проверки по PubMed — вручную они не правятся.
