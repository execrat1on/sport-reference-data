# Sport Reference — открытые данные

Датасет доказательного справочника о спортивных добавках и тренировках:
**549 публикаций PubMed**, **103 разобранных добавок** с уровнями
доказательности A/B/C и дозировками под цели, недельные тренировочные объёмы по группам мышц,
**25 упражнений**, **37 групп продуктов**, **160 продуктов**
с калориями и БЖУ на 100 г, **62 продукта** с гликемическим индексом,
**164 рецепта**, сравнения добавок, разборы заблуждений и
разделы о здоровье.

## Зачем это

Каждое утверждение на сайте сопровождается ссылкой на публикацию. Метаданные источников
не набирались вручную: заголовок, авторы, журнал, год и DOI подтягиваются из PubMed
E-utilities, а отдельный скрипт повторно сверяет базу с PubMed и падает, если запись
не найдена или не совпадает. Здесь лежит результат этой работы в машиночитаемом виде.

## Данные из внешних источников

Часть цифр взята не из исследований сайта, а из официальных таблиц. Мы указываем
источник, а у каждой позиции оставляем код или название, по которому значение
можно проверить:

- **Состав продуктов на 100 г** (`foods-nutrition.json`, а также пищевая ценность в
  `recipes.json`): ANSES, Table de composition nutritionnelle **Ciqual 2025**,
  <https://ciqual.anses.fr/>. Лицензия **Etalab 2.0** — открытая, требуется указание
  источника. Поле `sourceId` у каждой позиции — код продукта в таблице Ciqual.
- **Гликемический индекс** (`gi-table.json`): Atkinson FS, Foster-Powell K,
  Brand-Miller JC. International Tables of Glycemic Index and Glycemic Load Values:
  2008. Diabetes Care. Статья в свободном доступе в PubMed Central,
  <https://pmc.ncbi.nlm.nih.gov/articles/PMC2584181/>. Поле `nameEn` — исходное
  английское название для сверки.

У 50 продуктов из 160 часть значений не заполнена: в исходной
таблице этих цифр нет. Это не пропуск выгрузки — список незаполненных полей лежит
в самом файле, в поле `missing`, и мы не подставляем туда оценки.

## Проверка целостности

`data/manifest.json` хранит версию датасета, дату выгрузки и отпечатки (SHA-256)
каждого файла. Скачанный файл можно сверить с описью; несовпадение отпечатка
означает, что файл изменили или он скачался не полностью.

Проверка запускается сама при каждом обновлении репозитория
(`.github/workflows/validate-dataset.yml`) и проверяет: файлы читаются,
обязательные поля на месте, числа в README совпадают с содержимым файлов,
отпечатки сходятся с описью. Локально — `node tools/validate-dataset.mjs`.

## Как ссылаться

Данные открыты по лицензии **[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)**:
используйте свободно, в том числе в коммерческих проектах, при одном условии — указать источник.
Данные из внешних таблиц (Ciqual, гликемический индекс) дополнительно требуют указания
их собственных источников, перечисленных выше.

Пример атрибуции:

> Данные: Sport Reference — доказательный справочник о добавках и тренировках,
> https://sportreference.online/, лицензия CC BY 4.0.

## Чего эти данные не означают

Это не медицинская рекомендация и не руководство к применению. Уровень A/B/C описывает
силу доказательств для конкретного утверждения, а не пользу для отдельного человека.
Дозировки приведены для взрослых и не заменяют консультацию врача. Там, где исследований
под цель не нашлось, вместо цифры стоит честная пометка — см. <https://sportreference.online/evidence/gaps/>.

## Обновление

Файлы выгружаются из основного проекта командой `node scripts/export-dataset.mjs`.
Метаданные публикаций обновляются скриптом проверки по PubMed — вручную они не правятся.
