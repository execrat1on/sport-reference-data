# Описание полей — простыми словами

Здесь разобрано, что лежит в каждом файле датасета и что означают значения
внутри. Файлы — обычный JSON в кодировке UTF-8; числа в продуктах и рецептах
даны на 100 г съедобной части или на порцию, как указано в самом файле.

Сначала — два общих правила, которые нужны для всех файлов.

## Ссылки на исследования

Почти в каждом файле есть поле `refs` — это короткие имена исследований
(например, `creatine_meta2017`). Расшифровка лежит в `data/references.json`:
там то же имя в поле `id`, а рядом заголовок, авторы, журнал, год, PMID и DOI.
Отдельно ходить в PubMed за названием не нужно.

## Уровни доказательности A, B, C

Это сила доказательств для конкретного утверждения, а не польза для человека.

| Уровень | Что за этим стоит |
|---|---|
| **A** | Систематические обзоры и мета-анализы: несколько исследований сходятся между собой |
| **B** | Отдельные качественные рандомизированные исследования (когда участников случайно делят на группы) |
| **C** | Данных мало: единичные работы, наблюдения, опыты на клетках или животных |

Пометка `doseRefPolicy: "inherit"` у добавки означает, что источники для дозировок
берутся из общего списка `refs` этой же добавки, отдельного списка нет.

## Типы публикаций (`type` в references.json)

| Значение | По-русски |
|---|---|
| `meta-analysis` | Мета-анализ (объединены данные нескольких исследований) |
| `systematic-review` | Систематический обзор |
| `review` | Обзор литературы |
| `rct` | Рандомизированное контролируемое исследование |
| `clinical-trial` | Клиническое исследование (без случайного распределения) |
| `cohort` | Наблюдение за группой людей |
| `case-report` | Описание отдельного случая |
| `qualitative` | Качественное исследование (интервью, опросы) |
| `position-stand` | Официальная позиция научного сообщества |
| `consensus` | Согласительное заключение группы специалистов |
| `guideline` | Клинические рекомендации |
| `pk-study` | Исследование того, как вещество усваивается и выводится |
| `diagnostic-accuracy` | Проверка точности диагностического метода |
| `mechanistic` | Работа о механизме действия |
| `pharmacogenetic` | Влияние наследственности на действие вещества |
| `in-vitro` | Опыт на клетках, вне живого организма |
| `animal` | Опыт на животных |

## Содержимое файлов

### `references.json` — публикации

Массив записей.

| Поле | Что это |
|---|---|
| `id` | Короткое имя, по которому на публикацию ссылаются другие файлы |
| `pmid` | Номер публикации в PubMed |
| `title` | Заголовок |
| `authors` | Авторы (первые, через запятую) |
| `journal` | Журнал |
| `year` | Год |
| `doi` | Постоянная ссылка на публикацию (у части старых работ отсутствует) |
| `url` | Страница в PubMed |
| `level` | Уровень доказательности A/B/C |
| `type` | Тип публикации (таблица выше) |

### `supplements.json` — добавки

| Поле | Что это |
|---|---|
| `id` | Имя добавки латиницей (используется в адресах сайта) |
| `name` | Название по-русски |
| `category` | Группа: `base` (базовые), `goal` (под цель), `recovery` (восстановление), `health` (здоровье), `overrated` (переоценённые) |
| `goals` | Для каких целей разобрана: `muscle`, `strength`, `recomp`, `fatloss`, `endurance` |
| `evidence` | Уровень доказательности добавки в целом, A/B/C |
| `verdict` | Вывод одной-двумя фразами: что реально показали исследования |
| `mechanism` | Как вещество действует |
| `dose` | Ориентир по дозе |
| `doseByGoal` | Доза под каждую цель: у каждой цели своё поле `dose` и «локальный» уровень `evidence` |
| `doseRefPolicy` | Откуда берутся источники для доз: `inherit` — из общего списка `refs` |
| `timing` | Когда принимать |
| `form` | Что покупать: форма выпуска и чем она отличается |
| `benefits` | Подтверждённые эффекты списком |
| `cautions` | Ограничения и оговорки списком |
| `interactions` | Взаимодействия с другими веществами и лекарствами |
| `populations` | Особые группы: `minors` (до 18), `pregnancy` (беременность), `conditions` (заболевания) |
| `thirdPartyTesting` | `true`, если добавке особенно важна независимая проверка на примеси |
| `doping` | Что об этом говорит запрет WADA и в чём риск примесей |
| `refs` | Ссылки на `references.json` |

### `training.json` — тренировочные объёмы

| Поле | Что это |
|---|---|
| `reviewed` | Когда данные пересматривали (год-месяц) |
| `intro` | Вступление |
| `muscleGroups` | Список групп мышц: `id` и русское `name` |
| `goals` | Пять целей: `fatloss`, `muscle`, `recomp`, `strength`, `endurance`. У каждой — ориентиры, недельные подходы по группам мышц, частота, нагрузка, повторения, запас до отказа, отдых, кардио |
| `rirTable` | Пояснение к «запасу повторений»: цифра, что она значит и где уместна |
| `principles` | Общие принципы тренировок |

### `exercises.json` — упражнения

| Поле | Что это |
|---|---|
| `note` | Оговорка: подсказка не заменяет тренера |
| `groups` | Группы мышц: `id`, `label` и список упражнений |
| `groups[].items[].name` | Название упражнения |
| `groups[].items[].cue` | Подсказка по технике |
| `groups[].items[].video` | Видео: `title`, `channel`, `url` |

### `foods.json` — продукты по группам

| Поле | Что это |
|---|---|
| `note` | Вступление |
| `groups[].id`, `label`, `hint` | Группа, её название и на что обратить внимание |
| `groups[].items[].name`, `note` | Продукт и короткая заметка |

Здесь нет цифр: это навигационный список. Числа — в `foods-nutrition.json`.

### `foods-nutrition.json` — состав продуктов на 100 г

| Поле | Что это |
|---|---|
| `note` | Что внутри и откуда цифры |
| `source` | Источник: ANSES Ciqual 2025, ссылка, лицензия, дата получения |
| `items[].id` | Имя продукта по-русски для ссылок |
| `items[].name` | Название продукта |
| `items[].category` | Категория продукта |
| `items[].sourceId` | Код продукта в таблице Ciqual — по нему значение проверяется |
| `items[].sourceName` | Название в таблице-источнике (французское или английское) |
| `items[].missing` | Каких полей не хватает в исходной таблице: мы не подставляем оценки |
| `items[].per100g` | На 100 г: `kcal`, `protein`, `fat`, `carbs`, `sugars`, `fiber`, `satFat` (белки, жиры, углеводы, сахара, клетчатка, насыщенные жиры) |

### `gi-table.json` — гликемический индекс

| Поле | Что это |
|---|---|
| `note`, `source` | Пояснение и источник (международные таблицы 2008 года) |
| `items[].name` | Название по-русски |
| `items[].nameEn` | Исходное название для сверки с таблицей-источником |
| `items[].category` | Категория продукта |
| `items[].gi` | Гликемический индекс |
| `items[].giError` | Погрешность измерения |

Индекс измеряется для порции, в которой 50 г доступных углеводов, — это не
«индекс продукта вообще».

### `recipes.json` — рецепты

| Поле | Что это |
|---|---|
| `note`, `targetsNote`, `disclaimer`, `counted` | Правила отбора, оговорки и что не входит в расчёт |
| `targets` | Нормы на порцию: белки не меньше, углеводы и жиры не больше, коридор калорийности |
| `items[].id`, `title`, `category`, `goals` | Имя, название, категория и цели |
| `items[].time`, `servings` | Время приготовления в минутах и число порций |
| `items[].method` | Способ приготовления |
| `items[].ingredients` | Ингредиенты: `id` (код продукта в Ciqual), `grams`, `note` |
| `items[].steps` | Шаги приготовления |

Пищевая ценность порции считается из ингредиентов по таблице Ciqual 2025.
Соль, специи, зелень и вода в расчёт не входят.

### `comparisons.json` — сравнения добавок

| Поле | Что это |
|---|---|
| `_comment` | Пояснение, как составлен список |
| `pairs` | Пары из двух `id` добавок — что с чем сравнивают |

### `myths.json` — разбор заблуждений

| Поле | Что это |
|---|---|
| `items[].id` | Имя утверждения |
| `items[].claim` | Само утверждение |
| `items[].verdict` | Вердикт: миф, правда или полуправда |
| `items[].short` | Короткий ответ |
| `items[].explain` | Разбор |
| `items[].level` | Уровень доказательности разбора, A/B/C |
| `items[].refs` | Ссылки на `references.json` |

### `health.json` — разделы о здоровье

| Поле | Что это |
|---|---|
| `topics[].id`, `title`, `nav` | Имя раздела, заголовок и короткое название для меню |
| `topics[].summary` | Краткое введение |
| `topics[].signs` | На что обратить внимание |
| `topics[].prevention` | Профилактика |
| `topics[].doctor` | Когда идти к врачу |
| `topics[].exams` | Какие обследования обсуждают с врачом |
| `topics[].supplements` | Какие добавки связаны с темой |
| `topics[].urgent` | Что требует срочного обращения |
| `topics[].refs` | Ссылки на `references.json` |

Текст носит справочный характер и не заменяет консультацию врача.

### `symptoms.json` — навигатор по симптомам

| Поле | Что это |
|---|---|
| `note` | Оговорка: это не диагностика |
| `emergency` | Памятка «когда звонить 112»: заголовок, текст и номер |
| `groups[].id`, `label` | Группа симптомов (сердце, печень, гормоны и так далее) |
| `groups[].items[].label` | Симптом |
| `groups[].items[].urgent` | `true`, если нужна скорая помощь |
| `groups[].items[].signs` | Как это проявляется |
| `groups[].items[].action` | Что делать |

### Форматы ссылок

| Файл | Что это |
|---|---|
| `references.csv` | Те же публикации таблицей (UTF-8 с BOM, чтобы Excel не ломал кириллицу) |
| `references.bib` | BibTeX для менеджеров ссылок (Zotero, Mendeley) |
| `references.ris` | RIS для тех же программ |
| `supplements.csv` | Добавки таблицей |

### `manifest.json` — опись

| Поле | Что это |
|---|---|
| `version` | Версия датасета |
| `generated` | Дата выгрузки |
| `source`, `repository`, `license` | Сайт-источник, репозиторий и лицензия |
| `counts` | Число записей по каждому разделу |
| `files[].name`, `bytes`, `records` | Файл, его размер и число записей |
| `files[].sha256` | Отпечаток файла: по нему проверяют, что файл не изменился |

Проверить скачанные файлы: `node tools/validate-dataset.mjs`.
